Description

The Tic Tac Toe Bamboo Game brings the classic game to life with a sustainable twist. Made from bamboo, the set includes 9 pieces, each marked with either an X or O. The goal is simple: be the first to line up three matching symbols. Ideal for players of all ages, the game is neatly stored in a sliding-lid pinewood box. Includes game rules.
