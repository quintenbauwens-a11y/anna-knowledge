File guidelines

Save your files in uneditable, print-ready file formats.

If you already have a design, no worries; we accept other file formats, including JPEG, PNG, or EPS.

For photographic content, high-resolution JPEGs are recommended, preferably without compression. For graphics or text-based content, we recommend print-ready, vector-based PDFs. For content that is a combination of graphics and photography, we suggest using print-ready PDFs to ensure the best quality.

Submit your file in Vector (1-4 colours or embroidery) or in Pixels (Full colour print)

What printing techniques are used for this product?

Screen printing is a technique that involves using a woven mesh screen to support an ink-blocking stencil to print a desired image. This method is suitable for larger quantities, as it is more cost-effective than DTG.

Digital transfer print is a technique where a design is printed onto a special transfer paper and then permanently applied to a product using heat and pressure. This method allows for detailed, full-colour images to be transferred onto various materials like fabrics, ceramics, or plastics.
