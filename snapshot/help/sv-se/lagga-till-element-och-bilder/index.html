Lägga till element och bilder

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/21

Kategori: Canva

Hur lägger jag till element, ramar med mera?

Klicka på fliken Element i sidopanelen och sök efter specifika element i sökfältet. Du kan också bläddra bland alla element genom att klicka på Visa alla. Bland elementen finns former, linjer, illustrationer, ikoner, ramar, rutnät, dekaler, diagram och gradienter. Vill du lägga till en ram gör du likadant men söker på 'borders' i sökfältet.

Hur lägger jag till bilder från Canva i mina designer?

Klicka på fliken Foton i redigerarens sidopanel. Sök efter specifika bilder genom att skriva sökord i sökfältet eller klicka på föreslagna kategorier. Klicka på en bild för att lägga till den i din design. Bilder du använder samlas under Nyligen använda på fliken Foton. Du kan använda bilder som bakgrund genom att högerklicka och sedan välja att ändra bakgrunden.

Hur laddar jag upp egna bilder?

Du kan ladda upp egna bilder att använda i dina designer. Klicka på fliken Uppladdningar i redigerarens sidopanel. Markera och dra bilden för att ladda upp den, eller klicka på knappen Ladda upp. När den har laddats upp klickar du på bilden för att lägga till den i din design. Sedan kan du enkelt ändra storlek, justera inställningar eller lägga till specialfilter och effekter direkt i Canva!
