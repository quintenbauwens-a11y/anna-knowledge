Behöver jag bädda in bilderna i min design?

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/235

Kategori: Att tänka på

Ja! Bilder som inte bäddas in ordentligt kan orsaka olika problem, som att bilderna försvinner.

Inbäddning innebär att all nödvändig information om en bild finns med i filen med grafiken, så att den kan återges korrekt vid tryck.

Genererad från Contentful (hjälpcenterpost hcArt-235) för Annas kunskapsbas.
