Varför fungerar inte min rabattkod?

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/337

Kategori: Innan du beställer

Om du fick rabattkoden via ett nyhetsbrev eller ett kampanjmejl, dubbelkolla villkoren som står i mejlet. Koden kan ha gått ut, nått gränsen för rabatten eller inte gälla vissa produkter.

Tänk på att du bara kan använda en rabattkod per köp.
