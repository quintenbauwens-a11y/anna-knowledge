Hur lägger jag till element, kanter med mera i Canva?

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/321

Kategori: Canva

Klicka på fliken för element i sidopanelen och använd sökfältet för att leta efter specifika element. Du kan också bläddra bland alla element genom att klicka på Visa alla. Element omfattar former, linjer, illustrationer, ikoner, ramar, rutnät, klistermärken, diagram och gradienter. Vill du lägga till en kant gör du på samma sätt, men söker på ordet kanter i sökfältet.
