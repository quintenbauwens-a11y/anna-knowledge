Var skärs min färdiga produkt?

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/259

Kategori: Skapa din egen design

Vi vet var vi ska skära tack vare skärmärken.

Skärmärken är linjer som läggs till i kanterna på grafiken för att visa var trycket ska skäras efter tryckningen. Märkena visar tryckeriet var materialet ska skäras för att få rätt slutformat.

Genererad från Contentful (hjälpcenterpost hcArt-259) för Annas kunskapsbas.
