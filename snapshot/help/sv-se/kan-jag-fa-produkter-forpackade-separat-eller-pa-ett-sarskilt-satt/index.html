Kan jag få produkter förpackade separat eller på ett särskilt sätt?

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/271

Kategori: Innan du beställer

Även om det inte erbjuds som ett standardalternativ i vår beställningsprocess går det att begära. För att avgöra om det är möjligt för din beställning, och om några extra kostnader tillkommer, fyll i vår offertförfrågan. Vi strävar efter att svara med ett erbjudande inom två arbetsdagar.
