Kan jag få min beställning levererad till en mässa eller ett event?

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/171

Kategori: Leveransalternativ

Det går, men vi rekommenderar det inte eftersom det kan orsaka förseningar, särskilt om det inte finns någon namngiven mottagare. Vi rekommenderar att du anger en bostads- eller företagsadress för att leveransen ska gå snabbt.
