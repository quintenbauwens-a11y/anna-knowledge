Hur avregistrerar jag mig från nyhetsbrevet?

Hjälpcenterartikel på Helloprint Sverige: https://www.helloprint.com/sv-se/cs/articles/361

Kategori: Konto

Det är helt förståeligt om du vill avregistrera dig från vårt nyhetsbrev. Den här artikeln guidar dig genom hur du gör. Här är en enkel steg-för-steg-guide som hjälper dig att avregistrera dig:

  1. Gå till 'Mitt konto' genom att hålla muspekaren över ditt namn längst upp till höger på skärmen.
  2. Klicka på 'E-postinställningar' som du hittar bland alternativen i Mitt konto till vänster på skärmen.
  3. Markera eller avmarkera de typer av e-post du vill få från oss.
  4. Klicka på den blå knappen 'uppdatera e-postinställningar' för att bekräfta dina val.

Om du har avmarkerat alla ämnen men fortfarande får e-post från oss, tveka inte att kontakta våra tryckexperter här. Vi undersöker problemet och ser till att det löser sig.
