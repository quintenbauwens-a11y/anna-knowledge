Comment puis-je télécharger les designs de mes commandes précédentes ?

Article du centre d'aide sur Helloprint Belgique (FR): https://www.helloprint.com/fr-be/cs/articles/388

Catégorie: Après la commande

Vous pouvez télécharger les designs que vous avez déjà imprimés dans “Mon compte”

  1. Accédez à “Commandes“ dans“Mon compte“
  2. Sélectionnez la commande à partir de laquelle vous souhaitez télécharger les designs
  3. Sur la page de commande, vous pouvez télécharger les designs originaux que vous avez utilisés et un PDF prêt à imprimer que nous utilisons pour l'impression.
