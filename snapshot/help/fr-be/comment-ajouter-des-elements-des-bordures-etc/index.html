Comment ajouter des élements, des bordures, etc.

Article du centre d'aide sur Helloprint Belgique (FR): https://www.helloprint.com/fr-be/cs/articles/321

Catégorie: Canva

Cliquez sur l'onglet "Éléments" situé dans le menu de gauche et utilisez la barre de recherche pour trouver des éléments spécifiques. Vous pouvez également parcourir tous les éléments en cliquant sur “Afficher tout". Les éléments comprennent les formes, les lignes, les illustrations, les icônes, les cadres, les grilles, les autocollants, les graphiques et les dégradés. Si vous souhaitez ajouter une bordure, il vous suffit de suivre le même processus mais de rechercher "bordures" dans la barre de recherche.
