Catégorie: Concepts de base en design

Ce n'est pas nécessaire, nous les ajouterons toujours lors de notre vérification. Si vous souhaitez les ajouter, vous pouvez le faire en utilisant la couleur d'enregistrement. De quoi s'agit-il ? Les marques de repérage permettent de s'assurer que toutes les couleurs de l'œuvre imprimée sont correctement alignées. C'est pourquoi ces marques sont imprimées en utilisant 100 % de chaque encre du mélange CMJN. Il est important d'éviter d'utiliser cette couleur comme élément de conception, car elle pourrait rendre le texte flou ou provoquer des bavures sur le produit final.
