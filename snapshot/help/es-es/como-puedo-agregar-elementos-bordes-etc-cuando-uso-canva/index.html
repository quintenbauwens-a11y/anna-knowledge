¿Cómo puedo agregar elementos, bordes, etc., cuando uso Canva?

Artículo del centro de ayuda en Helloprint España: https://www.helloprint.com/es-es/cs/articles/321

Categoría: Canva

Haz clic en la pestaña de elementos del panel lateral y utiliza la barra de búsqueda para buscar elementos específicos. También puede examinar todos los elementos haciendo clic en "Ver todos". Los elementos incluyen formas, líneas, ilustraciones, iconos, marcos, cuadrículas, pegatinas, gráficos y degradados. Si quieres añadir un borde, sigue el mismo proceso pero busca "bordes" en la barra de búsqueda.
