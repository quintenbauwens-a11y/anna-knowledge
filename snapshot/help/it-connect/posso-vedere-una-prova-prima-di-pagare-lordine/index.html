Posso vedere una bozza prima di pagare l'ordine?

Articolo del centro assistenza su Helloprint Connect Italia: https://helloprint.elevio.help/it/articles/342

Categoria: Prima di ordinare

Sì, se il tuo file supera il nostro controllo grafica Basic: vedi la bozza digitale entro circa 5 minuti, prima di pagare. Se il file richiede un controllo manuale da parte del nostro team grafico, il controllo parte quando abbiamo ricevuto il pagamento.

Se il tuo file supera il controllo grafica Basic

Carica il file sulla pagina prodotto mentre ordini. Entro circa 5 minuti il controllo grafica Basic ti mostra la bozza digitale, così vedi esattamente cosa stamperemo prima di pagare. Il tuo ordine va in produzione dopo il pagamento e dopo che hai approvato la bozza digitale.

Se il tuo file richiede un controllo manuale

Alcuni file richiedono un controllo manuale da parte del nostro team grafico. Il controllo manuale parte quando abbiamo ricevuto il pagamento e dura circa 60 minuti. Poi ricevi la bozza digitale da approvare. Se la approvi dopo la scadenza, la data di consegna slitta di un giorno lavorativo.

Se carichi il file dopo il checkout

Puoi caricare il file anche nella pagina di conferma dell'ordine dopo il checkout, oppure più tardi dalla pagina del tuo ordine. Controlliamo il file e ti inviamo la bozza digitale da approvare. Carica e approva prima della scadenza per mantenere la data di consegna che hai scelto.

Se vuoi cambiare il file

Puoi sostituire il file finché l'ordine non va in produzione. Controlliamo il nuovo file e creiamo una nuova bozza digitale da approvare.

Il controllo manuale parte solo dopo aver ricevuto il pagamento: paga in tempo per approvare la bozza digitale prima della scadenza.
