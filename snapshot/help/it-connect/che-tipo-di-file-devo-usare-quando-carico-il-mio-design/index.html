Che tipo di file devo usare per la stampa?

Articolo del centro assistenza su Helloprint Connect Italia: https://helloprint.elevio.help/it/articles/241

Categoria: Creazione della tua grafica

Se puoi, carica un PDF: mantiene colori, font e risoluzione del tuo design esattamente come li hai creati. Accettiamo anche AI, EPS, PSD, TIFF, PNG, JPG, SVG e file Office (DOC, DOCX, XLS, XLSX, PPT e PPTX), fino a 500 MB per file.

Formati di file che accettiamo

  • PDF è il formato che consigliamo per tutti i prodotti, anche per i design con più pagine.
  • AI, EPS e SVG sono ideali per loghi e grafiche vettoriali.
  • JPG, PNG, TIFF e PSD vanno bene per la stampa se l'immagine ha una risoluzione abbastanza alta.
  • DOC, DOCX, XLS, XLSX, PPT e PPTX (file Office) sono accettati anche loro. Dopo il caricamento, un file Office può mostrare "Anteprima non disponibile".

La dimensione massima è di 500 MB per file.

Formati di file che non accettiamo

Non accettiamo file ZIP, RAR o GIF. Salva o esporta il tuo design in PDF, o in uno degli altri formati indicati sopra, e carica quel file.

Se il tuo design è in InDesign o in un altro programma di grafica

Esporta il design in PDF prima di caricarlo. Funziona allo stesso modo in InDesign, Figma, Sketch, QuarkXPress e negli altri programmi Adobe.

Se il tuo design è composto da più file

Puoi caricare più file per un solo prodotto. Li uniamo in un unico documento per il controllo grafica, quindi il numero totale di pagine non deve superare quello del tuo prodotto. Vedi caricare un design fronte-retro o con più pagine.

Prepara il file per la stampa

Un file pronto per la stampa deve avere anche il metodo colore, la risoluzione e la smarginatura giusti. Controlla i requisiti dei file per i prodotti in carta prima di caricare.

Cosa succede dopo il caricamento

Controlliamo il file e ti inviamo una bozza digitale da approvare. Scopri quanto dura il controllo grafica. Se il file non si carica, scopri cosa fare quando il file non si carica.
