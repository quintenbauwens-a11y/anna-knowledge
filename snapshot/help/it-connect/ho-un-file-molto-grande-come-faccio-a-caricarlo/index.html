Ho un file molto grande, come faccio a caricarlo?

Articolo del centro assistenza su Helloprint Connect Italia: https://helloprint.elevio.help/it/articles/367

Categoria: Creazione della tua grafica

Puoi caricare file fino a 500 MB ciascuno e anche più file per un solo prodotto. Se un singolo file supera i 500 MB, riducilo, dividilo in più file oppure inviacelo con WeTransfer.

Carica file fino a 500 MB

Carica il file nella pagina prodotto, nella pagina di conferma dopo il pagamento oppure più tardi dalla pagina dell'ordine. Ogni file può arrivare a 500 MB. Controlliamo il file e ti inviamo una bozza digitale da approvare; in quanto dura il controllo grafica trovi quando aspettartela.

Carica più file per un prodotto

Puoi caricare più file per un solo prodotto, per esempio un file per pagina. Dalla pagina dell'ordine puoi caricare fino a 10 file alla volta. Per il controllo uniamo i file in un unico documento, quindi il numero totale di pagine non può superare quello del prodotto. Leggi come caricare una grafica fronte-retro o con più pagine.

Riduci il tuo file

  • Salva la grafica in PDF.
  • Usa immagini con la risoluzione che serve per la stampa. Immagini con una risoluzione più alta di quella indicata nei requisiti dei file per i prodotti in carta rendono il file più pesante, non la stampa più nitida.
  • Elimina i livelli nascosti e gli elementi che non usi nella grafica.
  • Dividi una grafica con più pagine in più file da massimo 500 MB ciascuno.

Non comprimere il file in formato ZIP o RAR: non li accettiamo. Leggi quale formato di file usare.

Se il file supera ancora i 500 MB

  1. Vai su wetransfer.com e aggiungi il tuo file.
  2. Inserisci hello@helloprint.com come destinatario.
  3. Inserisci il tuo indirizzo email.
  4. Scrivi il numero d'ordine nel messaggio.
  5. Avvia il trasferimento.

Con il numero d'ordine colleghiamo il file al tuo ordine.

Se il file non si carica per un altro motivo

Se il file è sotto i 500 MB e comunque non si carica, leggi cosa fare quando il file non si carica.

Se approvi la bozza digitale dopo la scadenza, la data di consegna slitta di un giorno lavorativo: invia per tempo i file più grandi.
