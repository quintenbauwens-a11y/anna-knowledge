Come scarico i design dei miei ordini precedenti?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/come-scarico-le-grafiche-dei-miei-ordini-precedenti

Categoria: Dopo aver ordinato

Apri l'ordine in Il mio account: nella pagina dell'ordine puoi scaricare il file originale che hai caricato e il PDF pronto per la stampa che abbiamo usato.

Scarica il tuo design

  1. Vai su Ordini in Il mio account.
  2. Apri l'ordine con il design che ti serve.
  3. Sul prodotto di quell'ordine, scarica il file che hai caricato oppure la bozza digitale con Scarica PDF della bozza.

Il file viene salvato sul tuo dispositivo, così puoi riutilizzarlo, modificarlo o inviarlo a un grafico.

Quando è disponibile il PDF pronto per la stampa

Puoi scaricare il PDF pronto per la stampa del tuo design dopo aver approvato la bozza digitale. Prima di allora puoi scaricare il file che hai caricato.

Se vuoi stampare di nuovo lo stesso design

Non serve scaricare e ricaricare il design. Ripeti l'ordine precedente direttamente dalla pagina dell'ordine.

Se vuoi modificare il design per un nuovo ordine

Scarica il file originale, fai le modifiche e carica il nuovo file con il nuovo ordine. Lo controlliamo e ti inviamo una nuova bozza digitale da approvare.
