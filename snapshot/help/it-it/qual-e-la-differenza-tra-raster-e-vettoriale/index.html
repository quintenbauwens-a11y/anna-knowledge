Qual è la differenza tra raster e vettoriale?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/qual-e-la-differenza-tra-raster-e-vettoriale

Categoria: Definizioni comuni

Possiamo suddividere i file di progetto in due tipi principali: raster e vettoriale. I file raster sono composti da pixel, mentre i file vettoriali sono composti da equazioni matematiche che creano forme e linee.

I file raster sono ideali per immagini e fotografie. I file vettoriali, invece, sono migliori per loghi, icone e altri progetti che richiedono linee e forme nitide. Inoltre, i file vettoriali possono essere ingranditi o rimpiccioliti senza perdere qualità, mentre i file raster possono risultare pixelati se ingranditi troppo.
