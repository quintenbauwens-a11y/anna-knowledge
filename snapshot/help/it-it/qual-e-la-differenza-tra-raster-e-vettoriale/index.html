Qual è la differenza tra raster e vettoriale?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/qual-e-la-differenza-tra-raster-e-vettoriale

Categoria: Definizioni comuni

Un file raster è un'immagine fatta di pixel, come una foto; un file vettoriale è fatto di forme e linee descritte da formule matematiche, come la maggior parte dei loghi. I file vettoriali si possono ingrandire o ridurre senza perdere qualità, mentre i file raster diventano sgranati se li ingrandisci troppo.

File raster

Un file raster salva il tuo design come una griglia di pixel colorati. I file raster sono ideali per foto e immagini con molti colori e passaggi sfumati. La nitidezza di un file raster in stampa dipende dalla sua risoluzione nel formato in cui lo stampi.

I formati raster più comuni sono JPG, PNG, TIFF e PSD.

File vettoriali

Un file vettoriale salva il tuo design come forme, linee e curve. I file vettoriali sono ideali per loghi, icone, testi e altri design con linee nette e colori pieni. Un file vettoriale resta nitido in qualsiasi formato, dal biglietto da visita al grande banner.

I formati vettoriali più comuni sono AI, EPS e SVG. Un PDF può contenere forme vettoriali, immagini raster o entrambe.

Quale file usare per la stampa

  • Usa un file vettoriale per logo e testi ogni volta che puoi.
  • Usa un file raster per le foto, con una risoluzione adatta al formato di stampa.
  • Combina entrambi in un unico PDF: leggi quale tipo di file usare per la stampa.

Se il tuo logo esiste solo come file raster

Usa la versione originale più grande dell'immagine, oppure chiedi a chi ha disegnato il logo una versione vettoriale. Il nostro controllo grafica Basic segnala un'immagine a bassa risoluzione sulla tua bozza digitale, così puoi sostituire il file prima di approvare.
