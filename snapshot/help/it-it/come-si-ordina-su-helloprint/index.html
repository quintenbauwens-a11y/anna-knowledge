Come si ordina su HelloPrint?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/come-si-ordina-su-helloprint

Categoria: Prima di ordinare

Ordinare richiede quattro passaggi: scegli un prodotto, imposta le opzioni, scegli la data di consegna e aggiungi il tuo design. Puoi caricare il tuo file, creare il design con Canva oppure caricare il file più tardi.

Ordina in 4 passaggi

  1. Scegli un prodotto dal menu o con la barra di ricerca.
  2. Imposta le opzioni nella pagina prodotto: formato, quantità, tecnica di stampa, finitura e rilegatura.
  3. Scegli la data di consegna. La spedizione è gratuita sopra un importo minimo d'ordine: leggi quando la spedizione è gratuita. L'opzione di consegna più rapida ha un costo in più.
  4. Aggiungi il tuo design e vai al carrello.

Tre modi per aggiungere il tuo design

Se hai un file pronto per la stampa

Carica il tuo file. Nella pagina prodotto trovi i template e i requisiti dei file.

Se non hai ancora un design

Crealo con Canva. Dopo aver creato il design in Canva non puoi più cambiare la quantità né il template, quindi sceglili con attenzione prima di iniziare.

Se il tuo design non è ancora pronto

Effettua subito l'ordine e carica il file più tardi, nella pagina di conferma dell'ordine o dalla pagina dell'ordine. Caricalo e approvalo entro la scadenza per rispettare la data di consegna scelta.

Nel carrello

Controlla l'ordine, aggiungi un codice sconto o modifica le opzioni. Puoi anche scegliere un controllo grafica Premium o Deluxe a pagamento; ogni ordine include il controllo grafica Basic gratuito.

Cosa succede dopo

  1. Controlliamo il tuo file. Se supera il controllo grafica Basic, vedi la bozza digitale prima di pagare: leggi vedere la bozza prima di pagare e quanto dura il controllo grafica.
  2. Paghi e approvi la bozza digitale.
  3. Parte la produzione e il file non si può più cambiare.
  4. Spediamo l'ordine e ti inviamo un link di tracciamento.

Quando l'ordine è in produzione, non puoi più cambiare il file.
