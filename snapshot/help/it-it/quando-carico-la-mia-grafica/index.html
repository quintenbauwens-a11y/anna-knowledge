Quando carico il mio file grafico?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/quando-carico-la-mia-grafica

Categoria: Prima di ordinare

Puoi caricare il file prima o dopo il pagamento. Per ricevere l'ordine nella data scelta, carica il file e approva la bozza digitale entro la scadenza indicata accanto a quell'opzione di consegna.

Carica nella pagina prodotto, prima di pagare

  1. Scegli le opzioni e la data di consegna nella pagina prodotto.
  2. Carica il tuo file.
  3. Vai al carrello e paga con uno dei metodi di pagamento.

Cosa succede dopo: se il file supera il controllo grafica Basic, la tua bozza digitale è pronta in circa 5 minuti, prima del pagamento. Controllala e approvala per mandare l'ordine in produzione.

Carica nella pagina di conferma dell'ordine, dopo il checkout

  1. Scegli le opzioni e la data di consegna e paga l'ordine.
  2. Carica il file nella pagina di conferma dell'ordine che si apre dopo il checkout.

Cosa succede dopo: controlliamo il file e ti inviamo una bozza digitale da approvare. La produzione parte solo dopo che hai approvato la bozza digitale.

Carica più tardi dalla pagina dell'ordine

  1. Apri l'ordine in Ordini.
  2. Carica il file nella pagina dell'ordine.
  3. Controlla la bozza digitale e approvala.

Cosa succede dopo: controlliamo il file e ti inviamo una bozza digitale da approvare. In Quanto dura il controllo grafica trovi quando aspettartela.

Dove trovi la scadenza

La scadenza è in fondo alla pagina prodotto, accanto a ogni opzione di consegna. Dopo l'ordine la trovi anche nella pagina dell'ordine. Leggi come assicurarti che il tuo ordine vada in produzione in tempo.

Se vuoi cambiare il file dopo averlo caricato

Puoi sostituire il file finché l'ordine non va in produzione. Un nuovo file significa una nuova bozza digitale da approvare. Scopri come cambiare il file dopo il caricamento.

Se approvi la bozza digitale dopo la scadenza, la data di consegna slitta di un giorno lavorativo.
