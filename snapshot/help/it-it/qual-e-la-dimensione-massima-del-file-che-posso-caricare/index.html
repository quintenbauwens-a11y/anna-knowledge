Qual è la dimensione massima del file che posso caricare?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/qual-e-la-dimensione-massima-del-file-che-posso-caricare

Categoria: Prima di ordinare

La nostra procedura di ordine standard supporta il caricamento di file fino a 250 MB. Per i file più grandi offriamo un caricatore alternativo che gestisce file fino a 1 GB.
