Devo aggiungere i segni di taglio al mio progetto?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/devo-aggiungere-i-segni-di-taglio-al-mio-progetto

Categoria: Definizioni comuni

No. Carica il file senza segni di taglio (chiamati anche crocini): li aggiungiamo noi durante il controllo grafica.

Cosa serve invece al tuo file

Al posto dei segni di taglio, il file deve avere la smarginatura e un margine di sicurezza. Nei requisiti del file per i prodotti in carta trovi le misure e le impostazioni esatte.

Dove compaiono i segni di taglio

La bozza digitale mostra le linee lungo cui tagliamo il prodotto. In Le linee e i segni sulla bozza digitale trovi il significato di ognuna.

Se il tuo file ha già i segni di taglio

Esporta di nuovo il file con i segni di taglio disattivati e caricalo. Se l'hai già caricato, sostituisci il file: creiamo una nuova bozza digitale da controllare.

Colore di registro

Il colore di registro stampa il 100% di ciascun inchiostro CMYK e serve solo per i segni di stampa. Non usarlo per testi o forme nel tuo design: può rendere il testo sfocato o lasciare sbavature sul prodotto.
