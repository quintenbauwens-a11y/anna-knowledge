Cosa include e cosa non include un controllo grafica Premium o Deluxe?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/cosa-include-e-cosa-non-include-un-controllo-grafica-premium-o-deluxe

Categoria: Controllo della grafica e prova digitale

Se scegli il controllo grafica Premium, significa che:

  • Facciamo controlli di base su risoluzione, dimensioni e colore.
  • I tuoi file vengono convertiti in un PDF verificato.
  • Ricevi una prova di stampa (prova digitale) prima della produzione.

Se scegli il controllo grafica Deluxe, significa che:

  • Facciamo tutto ciò che è incluso nel controllo Premium.
  • Inoltre, uno dei nostri esperti esamina il tuo design.
  • I tuoi file vengono ottimizzati con l'AI (se possibile).

Tuttavia, non siamo mai in grado di controllare:

  • I refusi.
  • L'overprint.
