Cosa include il controllo grafica Basic, Premium e Deluxe?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/cosa-include-e-cosa-non-include-un-controllo-grafica-premium-o-deluxe

Categoria: Controllo della grafica e prova digitale

Ogni ordine include il controllo grafica Basic gratuito: controlliamo il tuo file e creiamo una bozza digitale da approvare. Il controllo grafica Premium e quello Deluxe sono opzioni a pagamento con verifiche in più. Nessun controllo copre gli errori di ortografia o l'overprint.

Controllo grafica Basic

  • Il controllo grafica Basic è gratuito con ogni ordine.
  • Con il controllo grafica Basic facciamo controlli automatici su risoluzione, formato e impostazioni colore del tuo file e creiamo la tua bozza digitale.
  • Se il tuo file supera il controllo grafica Basic, vedi la bozza digitale prima di pagare: leggi come vedere la bozza prima del pagamento.

Controllo grafica Premium

  • Il controllo grafica Premium include tutto quello che c'è nel Basic.
  • Accettiamo tutti i formati di file.
  • Dove possibile, ottimizziamo i tuoi file con l'AI.
  • Convertiamo i tuoi file in un PDF verificato.

Controllo grafica Deluxe

  • Il controllo grafica Deluxe include tutto quello che c'è nel Premium.
  • Uno dei nostri esperti fa un controllo extra personale del tuo file, con priorità.
  • Il tuo design è garantito perfetto.

Scegli il tuo controllo grafica

Scegli il controllo grafica Premium o Deluxe nel carrello, dove vedi anche il prezzo. Clicca sulla (i) accanto a un controllo grafica per confrontare le tre opzioni. Se non scegli nessuno dei due, il tuo ordine riceve il controllo grafica Basic.

Cosa non copre nessun controllo grafica

  • Gli errori di ortografia nel testo.
  • Le impostazioni di overprint nel tuo file.

Controlla tu questi punti sulla bozza digitale prima di approvarla.

Cosa succede dopo

Dopo che hai caricato il file, lo controlliamo e creiamo la tua bozza digitale. Scopri quanto dura un controllo grafica. Approva la bozza digitale per mandare l'ordine in produzione. Se approvi dopo la scadenza, la data di consegna slitta di un giorno lavorativo.

Gli errori di ortografia vengono stampati esattamente come sono nel tuo file, perché nessun controllo grafica include la verifica dell'ortografia.
