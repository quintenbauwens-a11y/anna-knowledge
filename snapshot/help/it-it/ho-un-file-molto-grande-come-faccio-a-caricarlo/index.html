Ho un file molto grande, come faccio a caricarlo?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/ho-un-file-molto-grande-come-faccio-a-caricarlo

Categoria: Creazione della tua grafica

Sappiamo che a volte la creatività non ha limiti e che i tuoi file di grafica possono diventare davvero grandi. Ma non preoccuparti, ci pensiamo noi! Se hai un file molto grande da caricare, segui questa semplice guida per un'esperienza fluida e senza intoppi.

Passo 1: notifica automatica

Quando provi a caricare la tua grafica, il nostro sistema è pensato per essere intuitivo e utile. Se il file è troppo grande per il caricamento standard, riceverai una notifica automatica. La notifica ti informerà che la dimensione del file supera il limite e ti proporrà una soluzione alternativa.

Passo 2: modulo di caricamento alternativo

Clicca sul link per accedere al nostro modulo di caricamento alternativo. Questo modulo è pensato appositamente per i file più grandi, così puoi comunque inviare la tua grafica senza problemi. Stai tranquillo, abbiamo reso questa procedura il più semplice possibile.

Passo 3: hai ancora problemi?

Nel raro caso in cui il file resti troppo grande anche per il modulo alternativo, abbiamo un'altra soluzione! Puoi inviare i tuoi file tramite WeTransfer, un servizio di condivisione affidabile. Ecco come:

  • Vai su WeTransfer dal tuo browser.
  • Clicca su Aggiungi i tuoi file e seleziona il file o i file di grafica di grandi dimensioni che vuoi inviare.
  • Inserisci "ciao@helloprint.it" come indirizzo email del destinatario.
  • Inserisci il tuo indirizzo email, così possiamo confermare la ricezione e collegare i file al tuo ordine.
  • Indica il numero del tuo ordine nel modulo del messaggio.
  • Clicca su Trasferisci per avviare il caricamento.
  • WeTransfer genererà un link di download che puoi inserire nella tua email o nelle note dell'ordine come riferimento.

Siamo qui per aiutarti in ogni fase. Buona progettazione!
