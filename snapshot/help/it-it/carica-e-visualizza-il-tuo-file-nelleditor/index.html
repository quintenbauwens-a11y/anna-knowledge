Come carico e visualizzo il mio file nell'editor?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/carica-e-visualizza-il-tuo-file-nelleditor

Categoria: Creazione della tua grafica

Sui prodotti supportati puoi caricare il file nell'editor online della pagina prodotto e vedere il tuo design applicato al prodotto prima di aggiungerlo al carrello. L'anteprima resta abbinata all'articolo nel carrello e al checkout, così sai sempre quale design appartiene a quale articolo.

Carica e visualizza il tuo file

  1. Apri la pagina prodotto e scegli le opzioni.
  2. Scegli l'opzione per caricare e visualizzare il tuo file nell'editor.
  3. Carica il tuo file.
  4. Controlla l'anteprima: posizione, dimensioni e colori del design sul prodotto.
  5. Aggiungi il prodotto al carrello.

Cosa succede dopo: l'anteprima compare accanto all'articolo nel carrello e al checkout. Per la maggior parte dei prodotti regalo, l'anteprima è un mockup del tuo design sul prodotto.

Cosa succede dopo l'ordine

L'anteprima nell'editor è un rapido controllo visivo. Dopo l'ordine, il file passa il controllo grafica Basic gratuito e ricevi una bozza digitale: un'anteprima del tuo design esattamente come lo stamperemo. In Quanto dura il controllo grafica trovi quando sarà pronta la bozza digitale. Controllala e approva la bozza digitale per mandare l'ordine in produzione.

Se l'anteprima non ti convince

Prima di aggiungere il prodotto al carrello, modifica il design e carica il nuovo file nell'editor. Dopo l'ordine puoi ancora sostituire il file finché l'ordine non va in produzione: vai su Ordini → Dettagli dell'ordine → Modifica i file inviati. Un nuovo file significa una nuova bozza digitale da approvare. Leggi come cambiare il file dopo il caricamento.

Se il tuo prodotto non ha l'anteprima nell'editor

Carica il file nella pagina prodotto, nella pagina di conferma dell'ordine dopo il checkout oppure più tardi dalla pagina dell'ordine. In questo caso l'anteprima del prodotto è la bozza digitale.

Dopo che hai approvato la bozza digitale, l'ordine va in produzione e il file non si può più modificare.
