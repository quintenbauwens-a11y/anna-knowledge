Capire le note di preflight sulla tua prova

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/capire-le-note-di-preflight-sulla-tua-prova

Categoria: Creazione della tua grafica

Quando generiamo la tua prova, controlliamo automaticamente il file e tutto ciò che abbiamo trovato è elencato accanto alla prova. Le note sono di due tipi:

  • Applicati in automatico: correzioni sicure che abbiamo già fatto: RGB convertito in CMYK, abbondanza estesa, font incorporati. Non devi fare nulla, è solo utile saperlo.
  • Da controllare: cose che solo tu puoi valutare: un'immagine a bassa risoluzione, un testo vicino alla linea di taglio. Guarda ogni punto sulla prova. Vuoi correggere qualcosa? Scegli Carica nuovo design.

Approvare la prova significa che sei soddisfatto del file comprese queste note, quindi dedicaci un minuto prima di approvare. E una volta approvata è definitivo: il file va direttamente in produzione e non può più essere modificato.
