Il mio file non si carica: cosa posso fare?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/il-mio-file-non-si-carica

Categoria: Creazione della tua grafica

Se un file non si carica, di solito è più grande di 500 MB, è in un formato che non accettiamo oppure è bloccato dal browser o dalla connessione. Puoi anche ordinare subito e caricare il file più tardi dalla pagina dell'ordine, purché tu carichi e approvi entro la scadenza.

Il file è troppo grande

Te ne accorgi se il file supera i 500 MB: compare un messaggio che indica che il file è troppo grande, oppure il caricamento si interrompe a metà.

Cosa puoi fare: riduci le dimensioni del file, per esempio salvando il design come un unico PDF con immagini alla risoluzione che serve per la stampa. In Caricare un file molto grande ti spieghiamo come fare e cosa fare se il file è ancora troppo grande.

Il formato del file non è accettato

Te ne accorgi se non riesci a selezionare il file o se compare un messaggio sul formato. I file ZIP, RAR e GIF non sono accettati.

Cosa puoi fare: esporta il design in PDF o salvalo in un altro formato che accettiamo. In Che tipo di file usare trovi tutti i formati accettati.

Stai caricando più file

Te ne accorgi se alcuni file non compaiono quando ne carichi molti insieme dalla pagina dell'ordine: da lì puoi caricare fino a 10 file alla volta.

Cosa puoi fare: carica i file in gruppi da massimo 10. Uniamo i file in un unico documento per il controllo, quindi il numero totale di pagine non deve superare quello del tuo prodotto.

Il PDF è protetto da password o danneggiato

Te ne accorgi se il caricamento non riesce subito, anche se il file è piccolo ed è un PDF.

Cosa puoi fare: apri il design nel tuo programma di grafica ed esporta un nuovo PDF senza password né limitazioni di modifica, poi carica il nuovo PDF.

Il browser o la connessione bloccano il caricamento

Te ne accorgi se la barra di avanzamento si ferma, o se non succede nulla quando carichi, anche con un PDF piccolo.

Cosa puoi fare: aggiorna la pagina e riprova, oppure prova con un altro browser. Disattiva l'eventuale VPN e usa una connessione stabile. Se hai già ordinato, il tuo ordine resta salvato: puoi caricare il file dai tuoi ordini in qualsiasi momento prima della scadenza.

Se vedi "Anteprima non disponibile"

Dopo il caricamento, i file Office (DOC, DOCX, XLS, XLSX, PPT e PPTX) possono mostrare "Anteprima non disponibile". Controlla il design nella bozza digitale che ti inviamo prima di approvarla.

Se approvi la bozza digitale dopo la scadenza, la data di consegna slitta di un giorno lavorativo.
