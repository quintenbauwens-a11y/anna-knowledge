Devo incorporare le immagini nel mio design?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/devo-incorporare-le-immagini-nel-mio-design

Categoria: Cose da fare e da evitare nella grafica

Sì. Incorporando un'immagine, tutte le sue informazioni vengono salvate nel tuo file e l'immagine si stampa correttamente. Un'immagine solo collegata a un altro file sul tuo computer può mancare quando stampiamo il design.

Immagini incorporate e collegate

  • Incorporata: l'immagine è salvata all'interno del file e lo segue ovunque lo carichi.
  • Collegata: il file rimanda soltanto a un'immagine salvata altrove sul tuo computer. Senza quell'immagine, il file non può mostrarla.

Incorpora le immagini prima di caricare il file

  1. Inserisci o incorpora ogni immagine nel design invece di collegarla. La maggior parte dei programmi di grafica indica quali immagini sono collegate.
  2. Esporta il design in PDF. Scopri quale formato di file usare per la stampa.
  3. Apri il PDF sul tuo computer e controlla che ci siano tutte le immagini.

Controlla anche gli altri requisiti del file per i prodotti in carta, come la risoluzione e il testo convertito in tracciati.

Cosa succede dopo il caricamento

Controlliamo il tuo file e ti inviamo una bozza digitale. Prima di approvarla, verifica che ogni immagine sia al suo posto.

Se sulla bozza digitale manca un'immagine

Incorpora l'immagine, esporta di nuovo il file e sostituisci quello che hai caricato. Puoi sostituire il file finché l'ordine non va in produzione, e con un nuovo file ricevi una nuova bozza digitale. Scopri come cambiare il file dopo averlo caricato.

Quando l'ordine è in produzione, il file non si può più cambiare: controlla ogni immagine sulla bozza digitale prima di approvarla.
