Come carico un design fronte-retro o multipagina?

Articolo del centro assistenza su Helloprint Italia: https://www.helloprint.com/it-it/centro-assistenza/come-carico-la-grafica-fronte-retro-o-multipagina

Categoria: Prima di ordinare

Il modo più semplice è un unico PDF con tutte le pagine nell'ordine di stampa; per un prodotto fronte-retro è un PDF di due pagine. Puoi anche caricare più file per lo stesso prodotto: li uniamo in un unico documento per il controllo.

Carica un unico PDF

  1. Metti tutte le pagine del tuo design in un solo PDF, nell'ordine in cui vuoi stamparle.
  2. Carica il PDF nella pagina prodotto, nella pagina di conferma dopo il checkout oppure più tardi dalla pagina dell'ordine.
  3. Controlla ogni pagina ed entrambi i lati nella bozza digitale, poi approvala.

Una volta approvata la bozza digitale, il tuo ordine può entrare in produzione.

Carica più file per lo stesso prodotto

Se le pagine sono in file separati, puoi caricarne più di uno per lo stesso prodotto nella pagina prodotto, nella pagina di conferma dell'ordine o nella pagina dell'ordine. Dalla pagina dell'ordine puoi caricare fino a 10 file alla volta.

Uniamo i tuoi file in un unico documento per il controllo. Il numero totale di pagine non può superare quello del prodotto che hai ordinato. Prima di approvare, verifica l'ordine delle pagine nella bozza digitale.

Esempio: biglietti da visita fronte-retro

Per i biglietti da visita fronte-retro, carica un PDF di due pagine: la pagina 1 è il fronte, la pagina 2 il retro. Posizioniamo noi ogni lato in automatico.

Se vuoi design diversi sullo stesso prodotto

Ogni design si ordina come prodotto a sé, con il suo file. Leggi come ordinare prodotti con design diversi.

Se stai creando un opuscolo a punto metallico

Gli opuscoli a punto metallico hanno regole proprie per numero e ordine delle pagine. Consulta i requisiti dei file per gli opuscoli a punto metallico.

Se devi cambiare un file

Puoi sostituire il file finché l'ordine non entra in produzione. Controlliamo il nuovo file e ti inviamo una nuova bozza digitale da approvare.

Quando l'ordine è in produzione, il file non si può più cambiare.
