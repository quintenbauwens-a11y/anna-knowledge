Quel profil de couleur dois-je utiliser pour mon fichier?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/380

Catégorie: Création de fichiers

Nous utilisons FOGRA39 (ISO Coated V2) pour les produits couchés et FOGRA47 (ISO Uncoated V2) pour les produits non couchés. Si vous n'êtes pas sûr du mode de couleur de votre fichier ou de la façon de le préparer dans votre fichier, ne vous inquiétez pas, nous le convertirons toujours pour vous dans notre processus de vérification du travail artistique.
