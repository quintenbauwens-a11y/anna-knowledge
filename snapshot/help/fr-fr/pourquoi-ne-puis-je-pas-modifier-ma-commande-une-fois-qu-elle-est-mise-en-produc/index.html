Pourquoi ne puis-je pas modifier ma commande une fois qu'elle est mise en production ?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/277

Catégorie: Après la commande

Pour garantir un traitement efficace de toutes les commandes, nos sites de production utilisent un système de mise en file d'attente. Cela signifie que toute modification apportée à une commande déjà dans la file d'attente peut potentiellement entraîner des retards pour les autres commandes en attente. C'est pourquoi nous envoyons toujours une alerte avant de valider l'épreuve numérique, afin de vous donner la possibilité d'apporter les modifications nécessaires avant la mise en production. Il est essentiel de veiller à ce que l'épreuve soit approuvée avec le plus grand soin. Si vous avez choisi d'envoyer vos fichiers directement à notre site de production, vous devriez également avoir reçu un message d'alerte.
