Comment ajouter les finitions exclusives à mon fichier pour des produits avec spot-uv ou dorure?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/225

Catégorie: Création de fichiers

Pour que les finitions exclusives soient appliquées correctement, vous devez soumettre deux fichiers :

  • l'un avec votre design complet ( recto ou recto-verso)
  • Un autre avec uniquement les éléments de votre design où la finition doit être appliquée.

Sur le deuxième fichier, veillez à utiliser une couleur noire à 100 % l'endroit où la finition exclusive doit être appliquée. N'oubliez pas que la finition exclusive ne peut pas être appliquée entièrement sur le bord.

Pour plus d'informations et de gabarits, consultez la page du produit souhaité. Vous y trouverez un manuel sur la manière de configurer correctement vos fichiers.
