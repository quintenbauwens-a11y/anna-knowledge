Comment puis-je télécharger mes propres images dans Canva ?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/323

Catégorie: Canva

Vous pouvez télécharger vos propres images pour les utiliser dans vos créations. Dans le panneau latéral de l'éditeur, cliquez sur l'onglet "Téléchargements". Sélectionnez et faites glisser l'image pour la télécharger ou cliquez sur le bouton "Télécharger". Une fois l'image téléchargée, vous pouvez cliquer sur l'image pour l'ajouter à votre dessin ou modèle. Vous pouvez ensuite facilement redimensionner vos images, ajuster leurs paramètres ou appliquer des filtres et des effets spéciaux dans Canva !
