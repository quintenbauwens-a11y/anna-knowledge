Comment ajouter un bon de réduction à ma commande?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/334

Catégorie: Avant de commander

  1. Cliquez sur l'onglet "Vous avez un code promo?" sous le bouton "Continuer".
  2. Ajoutez votre code de réduction dans l'onglet
  3. Cliquez sur "Enregistrer" pour ajouter le code de réduction à votre panier.
  4. Le site web recalcule le montant total et affiche le montant de la réduction.
  5. Poursuivez la commande vers la page des information concernant la livraison.

Attention : Après le paiement et la finalisation d'une commande, vous ne pouvez plus ajouter de code de réduction.
