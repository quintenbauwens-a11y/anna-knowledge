Puis-je utiliser une boîte postale / point relais comme adresse de livraison ?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/170

Catégorie: Adresse de livraison

Cette option n'est malheureusement pas possible. Merci de toujours fournir une adresse résidentielle ou professionnelle.

Veuillez noter que si vous avez opté pour une livraison le samedi, vous devrez fournir une adresse résidentielle/personnelle pour éviter tout retard.
