Comment puis-je modifier l'adresse e-mail pour la réception de mes factures ?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/216

Catégorie: Facture

  1. Rendez-vous dans la section 'Mon Compte' en survolant votre nom dans le coin supérieur droit de votre écran.
  2. Faites défiler vers le bas jusqu'à ce que vous voyiez le champ 'Modifier vos détails'.
  3. Remplissez votre adresse e-mail préférée dans la section 'E-mail de facturation'.
  4. Cliquez sur 'Enregistrer'.
