Pourquoi mon bon de réduction ou code promo ne fonctionne pas?

Article du centre d'aide sur Helloprint France: https://www.helloprint.com/fr-fr/cs/articles/337

Catégorie: Avant de commander

Si vous avez reçu le code promo ou bon de réduction par le biais de nos newsletters ou d'un email promotionnel, veuillez vérifier les termes et conditions qui y figurent. Il se peut que le code soit expiré, que le montant maximal soit dépassé ou qu'il ne soit pas valable pour certains produits.

Notez que vous ne pouvez utiliser qu'un seul code de réduction par achat.
