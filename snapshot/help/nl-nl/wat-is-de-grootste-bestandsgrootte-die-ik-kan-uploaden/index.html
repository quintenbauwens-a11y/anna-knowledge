Wat is de grootste bestandsgrootte die ik kan uploaden?

Klantenservice-artikel op Helloprint Nederland: https://www.helloprint.com/nl-nl/cs/articles/387

Categorie: Voor het bestellen

Ons standaardbestelproces ondersteunt bestandsuploads tot 250 MB. Voor grotere bestanden bieden we een alternatieve uploader die bestanden tot 1 GB kan verwerken.

Gegenereerd uit Contentful (klantenservice-item hcArt-387) voor Anna's kennisbank.
