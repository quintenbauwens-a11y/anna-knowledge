Waarom heb ik een betalingsherinnering ontvangen?

Klantenservice-artikel op Helloprint Nederland: https://www.helloprint.com/nl-nl/cs/articles/188

Categorie: Betalingen

Vanaf het moment dat de betalingstermijn op de factuur is afgelopen, sturen wij eens per twee weken een betalingsherinnering per e-mail. Het is belangrijk om op tijd te betalen. Anders loop je het risico dat er extra kosten bij komen kijken. Houd er rekening mee dat het tot drie werkdagen kan duren om betalingen te verwerken.

Zo kunnen wij de situatie verder voor je uitzoeken en oplossen.
