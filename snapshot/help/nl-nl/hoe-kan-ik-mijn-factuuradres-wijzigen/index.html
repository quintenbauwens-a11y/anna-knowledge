Hoe kan ik mijn factuuradres wijzigen?

Klantenservice-artikel op Helloprint Nederland: https://www.helloprint.com/nl-nl/cs/articles/183

Categorie: Facturen

Om je factuuradres te wijzigen, kun je ons contactformulier invullen. Vermeld in het formulier je factuurnummer en de nieuwe gegevens. Dan passen wij het met plezier voor je aan!
