Kan ik een sample aanvragen?

Klantenservice-artikel op Helloprint Nederland: https://www.helloprint.com/nl-nl/cs/articles/167

Categorie: Voor het bestellen

Als je een voorbeeld wilt ontvangen, is het het beste om de minimale hoeveelheid van het product dat je nodig hebt te bestellen - je kunt deze informatie vinden op de afzonderlijke productpagina's nadat je de gewenste specificaties hebt ingevuld.

Let op: Een kleine drukoplage kan anders worden geproduceerd dan een grotere drukoplage vanwege de drukmethoden - daardoor kan er een kleine afwijking in kleuren zijn, maar het materiaal blijft hetzelfde.
