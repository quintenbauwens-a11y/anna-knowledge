Hoe kan ik het e-mailadres voor de facturatie aanpassen?

Klantenservice-artikel op Helloprint Nederland: https://www.helloprint.com/nl-nl/cs/articles/216

Categorie: Facturen

Bij HelloPrint kun je eenvoudig je accountgegevens bijwerken, zoals je factuur e-mailadres, door deze stappen te volgen:

  1. Ga naar 'Mijn Account' door met je muis over je naam rechtsboven op het scherm te bewegen.
  2. Scroll naar beneden totdat je het veld 'pas gegevens aan' ziet.
  3. Vul je gewenste e-mailadres in bij de sectie 'Facturatie e-mailadres'
  4. Klik op 'Opslaan.'
