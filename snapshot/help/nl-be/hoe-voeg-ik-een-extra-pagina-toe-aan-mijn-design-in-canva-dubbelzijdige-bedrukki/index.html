Hoe voeg ik een extra pagina toe aan mijn design in Canva? (Dubbelzijdige bedrukking)

Klantenservice-artikel op Helloprint België (NL): https://www.helloprint.com/nl-be/cs/articles/312

Categorie: Canva

Onderaan de pagina kan je via de knop '+ pagina toevoegen' een extra pagina toevoegen. Je kan dan scrollen tussen de verschillende pagina's in je ontwerp.

Gegenereerd uit Contentful (klantenservice-item hcArt-312) voor Anna's kennisbank.
