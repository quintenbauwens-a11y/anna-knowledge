Kan ik een postbus gebruiken als afleveradres?

Klantenservice-artikel op Helloprint België (NL): https://www.helloprint.com/nl-be/cs/articles/170

Categorie: Leveringsadres

Dit is helaas niet mogelijk. Voor een tijdige levering hebben wij altijd een consumenten- of zakelijk adres nodig.

Let op: heb jij gekozen voor een zaterdaglevering? Om ervoor te zorgen dat je levering ook echt plaatsvindt op zaterdag, hebben wij een consumentenadres nodig.
