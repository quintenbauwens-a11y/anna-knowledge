Mijn Track & Trace code doet het niet. Wat kan ik doen?

Klantenservice-artikel op Helloprint België (NL): https://www.helloprint.com/nl-be/cs/articles/214

Categorie: Tracken van je levering

Zodra je bestelling is verzonden, ontvang je een e-mail met de trackingslink om je bestelling te volgen. Heb je deze link geopend en kun je je pakket niet vinden? Geen paniek! Dit komt waarschijnlijk doordat de bezorger je pakket nog niet heeft gescand. Als dat het geval is, zal de trackingslink de volgende dag actief zijn.
