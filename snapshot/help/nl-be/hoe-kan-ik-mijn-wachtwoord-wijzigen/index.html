Hoe kan ik mijn wachtwoord wijzigen?

Klantenservice-artikel op Helloprint België (NL): https://www.helloprint.com/nl-be/cs/articles/263

Categorie: Account

Wil je jouw huidige wachtwoord veranderen? Dit kan je gewoon doen in jouw account!

  1. Zorg ervoor dat je ingelogd bent.
  2. Ga naar 'mijn account'.
  3. Zodra je dat hebt gedaan klik op 'Wijzig je gegevens'. Hier kun je, onderandere, jouw wachtwoord bijwerken.
