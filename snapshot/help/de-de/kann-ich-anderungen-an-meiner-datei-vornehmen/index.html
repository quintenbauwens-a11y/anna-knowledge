Kann ich Änderungen an meiner Datei vornehmen?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/377

Kategorie: Grafikprüfung und digitale Vorlage

Wenn Sie Ihren digitalen Korrekturabzug noch nicht überprüft haben, aber bereits wissen, dass Sie Änderungen an Ihrer aktuellen Datei vornehmen möchten, können Sie die Seite "Hochladen und Korrekturabzug" öffnen und die folgende Schaltfläche auswählen: "Es gibt einen Fehler in meiner Datei/ Ich möchte eine neue Datei hochladen".

Dies führt Sie zu einer Seite, auf der Sie eine neue Datei hochladen können. Wenn Sie den digitalen Korrekturabzug bereits genehmigt haben, finden Sie eine Schaltfläche zum Ändern der eingereichten Datei(en)". Wenn Sie auf diese Schaltfläche klicken, werden Sie auf eine Seite weitergeleitet, auf der Sie Ihre Dateien erneut hochladen können. Wenn diese Option nicht angezeigt wird, befindet sich Ihr Auftrag wahrscheinlich bereits in Produktion.

Wenn Ihr Auftrag angenommen oder in Produktion ist, sind Änderungen nicht mehr möglich.

Aus Contentful erzeugt (Hilfecenter-Eintrag hcArt-377) für Annas Wissensdatenbank.
