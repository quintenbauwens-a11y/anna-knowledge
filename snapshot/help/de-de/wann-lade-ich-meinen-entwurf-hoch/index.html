Wann lade ich meinen Entwurf hoch?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/331

Kategorie: Vor der Bestellung

Sie können Ihren Entwurf entweder vor oder nach der Zahlung hochladen, indem Sie die folgenden Schritte ausführen. Wenn Sie Ihr Kunstwerk vor der Zahlung hochladen möchten:

  1. Legen Sie das Produkt, das Sie bestellen möchten, in Ihren Warenkorb
  2. Gehen Sie zur Zahlungsseite
  3. Wählen Sie „Später weiterzahlen, zuerst meinen Entwurf hochladen“
  4. Fahren Sie mit dem Hochladen Ihres Entwurfs fort

Wenn Sie vor dem Hochladen Ihres Entwurfs bezahlen möchten:

  1. Legen Sie das Produkt, das Sie bestellen möchten, in Ihren Warenkorb
  2. Gehen Sie zur Zahlungsseite
  3. Wählen Sie eine der Zahlungsoptionen aus, um Ihre Bestellung direkt zu bezahlen (weitere Informationen zu den Zahlungsoptionen finden Sie in diesem Artikel).
  4. Fahren Sie mit dem Hochladen Ihres Entwurfs fort

Sobald Ihr Auftrag in Produktion ist, können Sie keine Änderungen mehr an Ihrem Bildmaterial vornehmen. Überprüfen Sie daher bitte alles gründlich, bevor Sie es genehmigen.
