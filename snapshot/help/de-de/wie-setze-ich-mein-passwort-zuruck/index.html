Wie setze ich mein Passwort zurück?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/265

Kategorie: Konto

Machen Sie sich keine Sorgen, wenn Sie Ihr Passwort vergessen haben und es ändern müssen! Das passiert jedem mal, und wir sind für Sie da. Sie können Ihr Passwort ganz einfach zurücksetzen, indem Sie die folgenden Schritte ausführen:

  1. Klicken Sie hier und geben Sie die mit Ihrem Konto verbundende E-Mail-Adresse ein.
  2. Kurz darauf erhalten Sie eine E-Mail mit der Aufforderung, ein neues Passwort zu erstellen.
  3. Klicken Sie auf den Button in der E-Mail, um auf eine neue Webseite weitergeleitet zu werden.
  4. Auf der Webseite finden Sie ein neues Passwort, das wir für Sie generiert haben und welches Sie benutzen können. Alternativ können Sie auf derselben Webseite ein Passwort Ihrer Wahl erstellen.
  5. Sobald Sie Ihr Passwort geändert haben, sind Sie wieder angemeldet und können alle Ihre Lieblingsdrucke bestellen!
