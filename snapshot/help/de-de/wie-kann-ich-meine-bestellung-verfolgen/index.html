Wie kann ich meine Bestellung verfolgen?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/168

Kategorie: Verfolgung der Lieferung

Sobald Ihre Bestellung versandt wurde, erhalten Sie eine Bestätigungs-E-Mail mit Informationen zur Verfolgung Ihrer Bestellung. Sie können den Status Ihrer Bestellung auch sehen, indem Sie sich bei Ihrem Konto anmelden, „Bestellungen“ links auf der Seite auswählen und die Bestellung anklicken, deren Status Sie sehen möchten. Auf diese Weise können Sie ganz einfach über den Status Ihrer Bestellung informiert bleiben.

Aus Contentful erzeugt (Hilfecenter-Eintrag hcArt-168) für Annas Wissensdatenbank.
