Kann ich eine vorherige Bestellung wiederholen?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/262

Kategorie: Nach der Bestellung

  1. Gehen Sie in Ihrem Konto zu 'Bestellungen', indem Sie mit der Maus über Ihren Namen oben rechts auf dem Bildschirm fahren.
  2. Gehen Sie zur Bestellübersichtsseite der betreffenden Bestellung, die Sie wiederholen möchten, indem Sie auf „Bestelldetails“ klicken. Die Bestelldetails finden Sie direkt neben Ihren Bestellinformationen.
  3. Sobald Sie auf der Bestelldetailseite gelandet sind, können Sie unter dem Produkt, das Sie erneut bestellen möchten, auf die Schaltfläche "Nachbestellen" klicken.
  4. Wählen Sie die Produkte aus, die Sie erneut bestellen möchten, und klicken Sie auf "Produkte zum Warenkorb hinzufügen". Wenn Ihre vorherige Bestellung eine Grafik enthält und Sie diese erneut benutzen möchten, wählen Sie "Mit diesem Design".
  5. Wenn Sie Änderungen an den Produktspezifikationen vornehmen müssen, ist das ebenfalls kein Problem. Klicken Sie auf das Stiftsymbol und Sie werden zur Produktseite weitergeleitet, wo Sie die Spezifikationen anpassen können. Wenn alles gut aussieht, können Sie einfach zu "Bezahlen & Hochladen" fortfahren. Hier können Sie Ihre bevorzugte Zahlungsmethode auswählen und Ihre Dateien hochladen, falls Sie eine andere Grafik benutzen möchten.
  6. Wenn Sie versucht haben, Ihre Bestellung zu wiederholen, aber auf unserer Website eine Fehlermeldung erscheint, haben wir wahrscheinlich etwas in unserem Backend für dieses spezifische Produkt geändert, was uns daran hindert, die Wiederholung anzubieten. Als Kunde können Sie das gleiche Produkt bestellen, indem Sie die Produktseite auf unserer Website aufrufen und die gleichen Spezifikationen und Mengen wie zuvor auswählen. Wenn das nicht funktioniert, können Sie uns über unser Kontaktformular kontaktieren.
