Ich möchte mein Passwort ändern, wo kann ich das tun?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/263

Kategorie: Konto

Um Ihr Passwort zu ändern, stellen Sie sicher, dass Sie angemeldet sind und klicken Sie einfach auf diesen Link. Navigieren Sie dort zum Button „Ihre Daten ändern“. Hier können Sie Ihr Passwort aktualisieren.
