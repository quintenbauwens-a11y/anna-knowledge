Wie kann ich die E-Mail-Adresse ändern, an die ich meine Rechnungen erhalte?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/216

Kategorie: Rechnung

Bei HelloPrint können Sie Ihre Kontoinformationen, wie z. B. Ihre E-Mail-Adresse an der Sie Rechnungen erhalten, ganz einfach aktualisieren, indem Sie die folgenden Schritte ausführen:

  1. Gehen Sie zu „Mein Konto“, indem Sie mit der Maus über Ihren Namen in der oberen rechten Ecke Ihres Bildschirms fahren.
  2. Scrollen Sie nach unten, bis Sie das Feld „Ihre Daten ändern“ sehen.
  3. Geben Sie im Abschnitt „Rechnungs-E-Mail“ Ihre bevorzugte E-Mail-Adresse ein.
  4. Klicken Sie auf „Speichern“.
