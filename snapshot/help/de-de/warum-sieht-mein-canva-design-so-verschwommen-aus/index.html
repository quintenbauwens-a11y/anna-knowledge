Warum sieht mein Canva-Design so verschwommen aus?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/319

Kategorie: Canva

Wenn Ihr Design verschwommen oder pixelig aussieht, gibt es zwei häufige Ursachen.

  • Die Verwendung von Bildern geringer Qualität kann zu unscharfen oder verpixelten Bildern führen. Laden Sie nach Möglichkeit nur qualitativ hochwertige Bilder mit 300 DPI hoch.
  • Haben Sie Filter verwendet? Einige Filter haben einen „weichmachenden“ Effekt, wenn sie auf ein Bild oder Design angewendet werden. Entfernen Sie einfach den Filter und prüfen Sie, ob sich die Qualität ohne ihn verbessert.
