"Kann ich meine Bestellung an mehrere Adressen liefern lassen?

Hilfecenter-Artikel auf Helloprint Deutschland: https://www.helloprint.com/de-de/cs/articles/172

Kategorie: Lieferadresse

Wussten Sie, dass Sie eine einzelne Bestellung bei HelloPrint aufgeben und diese an mehrere Adressen versenden lassen können? Fügen Sie beim Auschecken einfach die Lieferadresse für jeden Artikel in Ihrem Warenkorb hinzu. Senden Sie beispielsweise eine individuelle Tasse an Ihr Heimbüro und ein Marken-T-Shirt an Ihr Geschäft. Geben sie eine einzige Bestellung auf, lassen Sie sie aber dorthin liefern, wo Sie sie benötigen. Es ist nicht erforderlich, separate Bestellungen für verschiedene Standorte aufzugeben.

Sie können dies tun, indem Sie beim Bezahlvorgang die folgenden Schritte ausführen:

  1. Gehen Sie in Ihrem Warenkorb auf „Bezahlen und Dateien hochladen“. Sie gelangen zunächst zu den Lieferoptionen.
  2. Wählen Sie für jedes Produkt die gewünschte Adresse aus. Wenn sich Ihre Adresse noch nicht in Ihrem Adressbuch befindet, können Sie sie hinzufügen, indem Sie auf „Adresse ändern“ neben dem Haussymbol auf der linken Seite Ihrer Produktdetails klicken.
  3. Sobald Sie alles eingerichtet haben, fahren Sie mit dem restlichen Bestellvorgang fort.

Bitte beachten Sie: Es ist nicht möglich, ein einzelnes Produkt auf zwei Adressen aufzuteilen. Wenn Sie beispielsweise 1.000 Flyer an Ihr Heimbüro und weitere 1.000 an Ihr Geschäft senden möchten, fügen Sie diese bitte als zwei separate Produkte zu Ihrer Bestellung hinzu. Auf diese Weise werden sie für die Lieferung separat verpackt."
