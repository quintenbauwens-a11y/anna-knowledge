¿Cómo recibiré el reembolso?

Artículo del centro de ayuda en Helloprint Connect España: https://helloprint.elevio.help/es/articles/186

Categoría: Pago

El importe se transferirá utilizando el método de pago que utilizaste para realizar el pago inicialmente. El proceso suele tardar entre 3 y 8 días laborables.
