What file type should I use when uploading my design?

Help centre article on Helloprint US: https://www.helloprint.com/en-us/cs/articles/241

Category: Creating your design

The preferred format for print design is PDF, as it preserves design elements, colours, and resolution without compromising quality.

No need to sweat it if you've already handed in a different file format! We can still work with most of those too. Different file types have unique properties that make them ideal for specific purposes. For example, PDF files are print-ready and suitable for complex documents with multiple pages, while EPS files are perfect for vector logos and graphics.

Common file formats (JPG, PNG, PDF): JPG and PNG files are commonly used for web graphics but can be used for print materials if they have a high enough resolution. PDF files are the industry standard for print-ready documents. Do you have a Word file? Please save this as a pdf before submitting.

Specialised file formats (EPS, AI, INDD): EPS files are suitable for vector graphics, while AI files are preferred for complex designs. INDD files are used in desktop publishing and are suitable for multi-page documents.
