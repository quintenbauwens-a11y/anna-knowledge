I don't see all my designs on the print proof?

Help centre article on Helloprint US: https://www.helloprint.com/en-us/cs/articles/391

Category: Artwork check & digital proof

It looks like you've uploaded multiple designs to a single order or order line. Unfortunately, this will cause issues such as the files being declined or only one design being visible. Our system allows only one design per order item or print run as mentioned on most product pages.

How to Resolve:

  1. If you have multiple order lines but uploaded all designs to one order item, please divide the designs across the correct order lines.
  2. If you need more order lines, the order needs to be upgraded to so we can print all designs.

You can resolve this by canceling the current order and creating a new one with the correct setup.
