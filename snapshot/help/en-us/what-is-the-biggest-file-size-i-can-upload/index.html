What is the biggest file size I can upload?

Help centre article on Helloprint US: https://www.helloprint.com/en-us/cs/articles/387

Category: Before ordering

Our standard ordering process supports file uploads up to 250MB. For larger files, we offer an alternative uploader that can handle files up to 1GB.
