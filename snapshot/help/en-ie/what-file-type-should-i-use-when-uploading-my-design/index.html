What file type should I use for printing?

Help centre article on Helloprint Ireland: https://www.helloprint.com/en-ie/help-centre/what-file-type-should-i-use-when-uploading-my-design

Category: Creating your design

Upload a PDF if you can: it keeps the colours, fonts and resolution of your design exactly as you made them. We also accept AI, EPS, PSD, TIFF, PNG, JPG, SVG and Office files (DOC, DOCX, XLS, XLSX, PPT and PPTX), up to 500 MB per file.

File types we accept

  • PDF is the file type we recommend for every product, including designs with several pages.
  • AI, EPS and SVG work well for vector logos and graphics.
  • JPG, PNG, TIFF and PSD work for print when the image has a high enough resolution.
  • DOC, DOCX, XLS, XLSX, PPT and PPTX (Office files) are accepted too. An Office file may show "Preview not available" after you upload it.

The maximum size is 500 MB per file.

File types we don't accept

We can't accept ZIP, RAR or GIF files. Save or export your design as a PDF, or as one of the other file types above, and upload that file instead.

If your design is in InDesign or another design tool

Export your design as a PDF before you upload it. This works the same way in InDesign, Figma, Sketch, QuarkXPress and other Adobe programs.

If your design has several files

You can upload several files for one product. We combine them into one document for the design check, so the total number of pages must not be more than the page count of your product. See uploading a double-sided or multi-page design.

Make your file print-ready

A print-ready file also needs the right colour mode, resolution and bleed. Check the file requirements for paper products before you upload.

What happens after you upload

We check your file and send you a digital proof to approve. See how long the design check takes. If your file won't upload, see what to do when your file won't upload.
