Why is my discount voucher not working?

Help centre article on Helloprint Ireland: https://www.helloprint.com/en-ie/help-centre/why-is-my-discount-voucher-not-working

Category: Before ordering

If your discount code is not working, it is almost always mistyped, expired, already used, or not valid for the products in your cart. You can use one discount code per order.

The code is mistyped

You'll see this if the cart says the code is invalid straight away, even though the offer is still running.

What you can do: copy the code from the email or promotion and paste it again, with no spaces before or after it. The code must match exactly, including letters and numbers that look alike, such as 0 and O.

The code has expired

You'll see this if the end date in the email or promotion where you got the code has passed.

What you can do: an expired code can't be used any more, but there may be a current offer for you. Check our website, or sign up for our newsletter in My Account → Personal details → Communication preferences to hear about new offers.

The code has already been used

You'll see this if you have already placed an order with this code.

What you can do: check the conditions of the code to see how often you can use it. If it can't be used again, use another valid code or place your order without one.

The code doesn't apply to your cart

You'll see this if the conditions of the code mention specific products, categories or a minimum order value, and your cart doesn't meet them.

What you can do: change your cart so it meets the conditions, for example by adding the product the code is for. The discount then appears in your cart total.

Another code is already applied

You'll see this if your cart already shows a discount from another code.

What you can do: you can use one discount code per order, so remove the first code and enter the one that gives you the bigger discount. Adding a discount voucher to your order shows where to enter it.

If none of these is the cause

We look at the code with you.
