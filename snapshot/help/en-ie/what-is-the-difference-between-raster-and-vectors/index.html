What is the difference between raster and vectors?

Help centre article on Helloprint Ireland: https://www.helloprint.com/en-ie/help-centre/what-is-the-difference-between-raster-and-vectors

Category: Design definitions

A raster file is an image made of pixels, such as a photo; a vector file is made of shapes and lines described by mathematical formulas, such as most logos. Vector files can be scaled up or down without losing quality, while raster files become pixelated if you enlarge them too much.

Raster files

A raster file stores your design as a grid of coloured pixels. Raster files are best for photos and images with many colours and soft transitions. How sharp a raster file prints depends on its resolution at the size you print it.

Common raster file types are JPG, PNG, TIFF and PSD.

Vector files

A vector file stores your design as shapes, lines and curves. Vector files are best for logos, icons, text and other designs with crisp lines and flat colours. A vector file stays sharp at any size, from a business card to a large banner.

Common vector file types are AI, EPS and SVG. A PDF can contain vector shapes, raster images or both.

Which file to use for printing

  • Use a vector file for your logo and text wherever you can.
  • Use a raster file for photos, at a high enough resolution for the size you print.
  • Combine both in one PDF: see which file type to use for printing.

If your logo is only available as a raster file

Use the largest, original version of the image, or ask the person who designed your logo for a vector version. Our Basic design check notes a low-resolution image on your digital proof, so you can replace the file before you approve.
